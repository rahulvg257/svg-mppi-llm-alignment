# AISP Reproduction

Reproduction-focused implementation of deterministic decoding, Best-of-N, and AISP for:

- Base model: `TinyLlama/TinyLlama-1.1B-Chat-v1.0`
- Dataset: `Anthropic/hh-rlhf`
- Reward model: configurable Hugging Face sequence-level reward model

The code is organized for methodological reproduction of the paper's AISP algorithm under a smaller, course-project-friendly setup rather than for matching the paper's large-model results.
